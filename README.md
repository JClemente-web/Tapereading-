# Tapereading-

Base profissional para conceber, pesquisar, implementar, auditar e evoluir uma automação de Tape Reading no ProfitPro, com foco principal em Mini Dólar (WDO) e suporte operacional a Mini Índice (WIN).

## Objetivo

Criar uma automação profissional que interprete fluxo de ordens, agressões, absorções, desequilíbrios, exaustão, liquidez, notícias, correlações e comportamento de players, usando o ProfitPro como ambiente de execução e controle operacional.

## Premissas

- O foco principal é WDO, com WIN como ativo secundário e regras separadas.
- A solução deve automatizar leitura, decisão, execução, proteção, bloqueio e auditoria.
- Nenhuma regra entra em produção sem fonte rastreável, teste, replay, simulação e validação.
- A automação deve priorizar não operar quando as condições não estiverem completas.
- O projeto deve tratar capital real com controle de risco, logs e revisão sênior.

## Aviso de risco e responsabilidade

Este projeto trata de automação para ambiente real de mercado e, portanto, deve ser desenvolvido com validação, auditoria, limites de risco e homologação antes de qualquer execução com capital. A documentação não promete resultado e não substitui controles formais de risco, conformidade, corretora, plataforma e supervisão humana.
